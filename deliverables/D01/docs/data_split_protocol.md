# D01 数据采集与分集规范

版本 D01-split/0.1，2026年11月12日。此为本次提出的交接契约，尚未由 B、C、A 确认，不表示训练数据已经取得。与 D03、D04 共用 episode 级划分；Isolation Forest 只取训练集中的正常子集，多模态监督训练可取训练集中的已标注异常。

## 采集单位

每次 reset 开始一个 episode；终止、超时或人工选择 reset 后结束旧 episode，后续属于新 episode。一次控制循环、候选动作、D 审核记录均不能自动算作新 episode。重复运行相同确定性初态与策略产生的等价轨迹不作为独立统计样本。

B 的原始数值轨迹应逐步保存 episode_id、step_index、state_version、仿真时间及单位、UTC 采集时间、观测、候选动作、实际执行动作、reward、terminated、truncated、info 和错误。候选被拒绝时不得伪造执行后观测；日志应记录 executed=false 及拒绝依据。软件墙钟与仿真时间分别保存。

变量字典必须逐维给出索引、名称、单位、坐标形式、尺度转换、可观测性、来源与版本；不能由 o_0 等占位名推测物理量。当前适配器 normalize=False，但上游默认 uss_subtracted=True，不能把动作值不加解释地称为绝对流量。

## 来源与标签

数值为 native_simulation；从同一数值序列绘制的趋势图为 derived；项目生成的设备示意图和文本为 synthetic 或 derived，必须追溯当前 episode 与生成器版本；取得真实授权的外部数据才标 authorized_external。缺少视觉或文本保存空列表，不补造来源。

异常标签来自独立的扰动注入记录或已核验规则依据，记录发生步、结束步、目标变量、注入幅度和单位。正常 episode 的 event_start_step 与 event_end_step 均取0，表示无异常；检测评分时应先按 label_summary 区分，不能将正常步0当异常。多事件和恢复复杂标签存放独立逐事件标签文件，此版本清单只存覆盖首末事件的摘要区间。

R-02 越界候选标签只说明动作不满足接口域，不能作为泄漏、设备异常或生产失败标签。标签、异常类别词、故障编号、阈值命中说明和事后 D 结论不得作为模型输入文本或图像标注。输入文本只使用当步可获得的原始事件；标签文件与输入文件分开。

## 先分组再切窗

建议初始比例为训练60%、验证20%、测试20%，这是待团队确认的工程初值，不是样本量或统计功效保证。应先形成足够 episode，再按 lineage_group 分组分配，记录分配脚本、固定种子和实际列表。一个原始 episode 的所有切窗、图片、文本与扰动派生版本保持在同一集合；同源初始条件的近重复轨迹归同组。拟研究未知场景泛化时，另建整场景留出测试，不将普通随机分组称作未知场景验证。

所有切窗在单一 episode 内进行；不得跨 reset，不得跨集合。标准化、缺失值填充、特征选择、TF-IDF 词表只在训练集拟合。Isolation Forest 仅使用 iforest_train=true 的正常训练 episode；污染率等超参、检测阈值在验证集确定。训练和验证阶段不得查看测试标签或根据测试结果反复调参。

正式测试只在配置冻结后执行；测试集不足或异常种类不足则报告探索性结果。不得把同一轨迹切成许多重叠窗口后宣称有同样数量的独立样本。

## 对齐与校验

默认拟采用按 step_index 严格对齐，alignment_tolerance_steps=0。真实异步模态出现后，应依据采集周期制定容差并版本化；不预设未经核实的秒数。时序窗口只使用截至当前步的信息，禁止用未来帧、未来日志或完整 episode 统计给当前步预测。

清单保存 episode、根来源分组、代码提交、配置和初态哈希、种子、场景、权限证据、标签来源和模态文件哈希。derived_from 在本版本限定引用当前 episode；更复杂的跨 episode 合成须先升级契约并提供完整来源图。

scripts/validate_manifest.py 检查 JSON Schema、文件可读性及哈希、分组/文件跨集合重用、正常训练子集、摘要区间和声明的对齐误差。它不读取时序文件内容判断真实物理单位，不自动发现近重复轨迹，也不能证明权限、文本无泄漏或模型未窥视测试集。label_free_input_confirmed 只是交付者声明，D 仍须抽查输入和生成代码。

examples/data_manifest.draft.json 中零哈希是醒目标记，不是有效哈希。空数据集必须校验失败；没有真实数据时不能通过改状态伪装验收。
