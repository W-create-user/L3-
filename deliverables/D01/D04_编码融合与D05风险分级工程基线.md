## D04：实际运行的分支

`l3_system/monitoring/multimodal_model.py` 提供：

| 分支 | 实现 | 边界 |
|---|---|---|
| 视觉 | torchvision ResNet18，输出 16 维 | `weights=None`，未使用预训练权重；输入为已准备的 RGB 32×32 张量 |
| 时序 | 39 变量 LSTM，输出 16 维 | Atropine 专用；均值、标准差仅从训练集可用观测估计并保存在模型缓冲区 |
| 文本 | 训练集拟合 TF-IDF；MultinomialNB 独立基线；线性投影参与融合 | 词表不读取缺失文本、验证集或测试集 |
| 融合 | 拼接分类头、带掩码的注意力分类头 | 二分类实验模型；分数未经概率校准 |
| 消融 | 完整模型分别屏蔽到单一模态 | 使用完整模型验证集冻结阈值；属于推理时屏蔽，不是单模态重新训练比较 |

训练使用显式二元标签；训练集与验证集均须有两类，阈值只在验证集选择。测试集仅评估。分组跨划分会拒绝。文本朴素贝叶斯仅统计存在文本的样本，缺失样本单列弃权。缺失图像/时序/文本会先清除填充值再编码，融合时屏蔽相应嵌入；全部模态缺失直接拒绝评分。

CPU 烟雾验证使用 8/6/6 个合成训练、验证、测试样本，两个融合模式各实际反向传播并更新一轮。合成标签及文本信号由演示器构造，不能用其 F1 声称工艺检出率、泛化能力或多模态优越性。视觉随机初始化且只训练一轮，不能称为已训练完成的真实视觉模型。

本组件自身是内存张量实验 API。2026-11-13 新增 multimodal_intake 实验桥接，能够重新核验原始对齐清单并解码图像/文本；接口详见《D04_对齐清单到训练输入桥接.md》。真实应用仍需要授权及内容防泄漏审查、独立标签、模型部署语义绑定及可信保存/加载。现有 IF 的部署绑定不能自动扩展到本融合模型。未接入线上动作授权路径。

## D05：保守风险建议

`l3_system/monitoring/risk_policy.py` 是独立、显式调用的实验建议器。输入是有 episode/state_version 的硬规则判定、质量状态、上下文新鲜度、异常布尔结果及分布适用范围。它不自行估计 OOD，也不把异常分数转换为“安全概率”。`in_scope` 必须由后续可信适用范围检查提供，不能由策略代理自行声明。

| 等级 | 模式 | 行为 |
|---|---|---|
| 1 | request_review | 可提交到已有动作门禁复核；本组件始终 `execution_authorized=false` |
| 2 | restricted | 质量退化或恢复审查未完成，阻断自动执行 |
| 3 | takeover_requested | 硬规则拒绝、异常、过期、数据不可用、分布未知/越域、重复/倒序状态；阻断并请求接管 |

启动及 episode 重置默认限制。恢复需要显式人工审查确认和默认 3 个连续有效版本；任一严重问题清除确认与计数。重复状态不能累计恢复，间隔版本重新计数。人工确认本身不授权动作。它没有接管人员通信、自动执行或物理安全认证能力；未替换现有系统状态机。

## 2026-11-13：恢复确认接口收紧

输出版本升级为 `D05RiskAdvisory/0.2`。人工确认改为显式传入当前 `state_version` 与非空 `reviewer_ref`：

```python
policy.acknowledge_review(episode_id, state_version=current_version, reviewer_ref="review-record-id")
```

确认须对应已经评估的最新状态；旧版本、布尔型版本号、跨 episode 或缺少审查引用均拒绝。引用是审查记录标识，不是身份认证；调用者必须在外围完成授权。输出包含确认版本和引用的独立副本，便于审计。无效输入或 episode 错配会撤销既有恢复确认；严重事件后不能使用之前版本的确认。旧的仅传 episode 调用不再兼容。

## 2026-11-13：单模态独立重训补齐

新增 fusion_comparison 模块，分别独立重训 full_concat、full_attention、time_only、image_only、text_only、without_image、without_text 七组，每组独立使用自己的验证集定阈值。保留原 full-model 推理时屏蔽测试作为不同问题的诊断，不将两类结果混称。每组披露各划分可用样本和弃权数；可用样本集合可能不同，不能据此直接作公平排名或显著性结论。

视觉主干现在默认冻结参数及 BatchNorm 运行统计，仅视觉投影头可训练；未取得预训练权重，使用冻结随机特征，必须保留与计划中预训练语义特征的差异说明。无文本组使用固定中性词表占位、文本掩码为 false，不读取验证/测试文本拟合词表；朴素贝叶斯在训练文本缺失或不足两类时明确不可用并弃权。无时序组不从其他划分估计时序标准化。
