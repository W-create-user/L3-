# D04 对齐清单到训练输入桥接（2026-11-13）

新增 `l3_system/monitoring/multimodal_intake.py`，供实验阶段显式调用。它重新运行原始 D04Alignment/0.1 清单核验，不接收人工修改过的对齐输出作为可信入口；保留现有因果对齐、文件哈希、来源和分组跨划分检查。

输入另需 D04Labels/0.1 独立标签侧车，字段严格为：

| 字段 | 要求 |
|---|---|
| schema_version | D04Labels/0.1 |
| alignment_sha256 | 原始完整对齐清单的 binding.fingerprint 规范 JSON 指纹 |
| label_scope / source_kind | synthetic_fixture / synthetic_fixture，或 process_anomaly / independent_annotation |
| source_ref / reviewed_by | 非空来源与审查记录引用；声明不构成真实性或授权证明 |
| episodes | 每个纳入 episode 均有且只有一项，包含 episode_id、lineage_group、split、record_labels |
| record_labels | 与原始 series 逐记录对应的显式布尔数组，不接受 null、数值 0/1 或缺项 |

`excluded` episode 不纳入训练，也不得在侧车中冒充训练样本。真实包若只有空的工艺异常标签，此入口会拒绝，不能拿接口拒绝、动作越界或 reward 自动生成工艺真值。

## 转换约定

- 时间窗仅包含当前 record_index 及之前的连续记录，不跨 episode；最初 window_size−1 条仅作预热，不补齐、不读取未来。
- 训练目标是窗口末端记录的原始标签，不将事件区间向前后扩张；因此不是“窗口中任意异常”的标签语义。
- 图像仅接受单帧 RGB PNG/JPEG，最多 400 万像素；读取上限 8 MB，固定双线性缩放为 32×32，再转为 [0,1] CHW 张量。此变换是工程设定，未证明保留所有工艺信息。无图像以零张量配显式缺失掩码表示。
- 文本仅接受不超过 64 KB 的严格 UTF-8 非空文本。无文本以空字符串配缺失掩码表示。
- 解码使用的字节会再次核对哈希，防止前次对齐核验后文件改变。声明的生成器与内容防泄漏审查仍需独立复核，哈希不能证明没有标签泄漏。
- 现有对齐器核验时会读取完整源文件；上述读取预算约束的是后续解码入口，不是整个清单核验的全局内存上限。

## 调用

```python
from l3_system.monitoring.multimodal_intake import train_from_manifest
model, vectorizer, text_baseline, report = train_from_manifest(
    manifest, labels, root,
    window_size=4, mode="attention", epochs=1,
    allow_experimental=True,
)
```

默认拒绝实验入口，必须显式 opt-in。它使用现有训练集拟合的时序标准化、TF-IDF 及验证集阈值逻辑；返回原始清单、标签和变量绑定的指纹，以及每个划分的 episode/窗口末端索引。报告明确相关窗口不是独立 episode，不能用窗口数量冒充独立实验次数。

本轮在临时目录生成图像、文本及轨迹夹具，实际执行了“文件→对齐核验→独立标签校验→张量→注意力模型训练→验证阈值→测试”的完整工程路径。测试夹具包含人工构造信号，仅证明路径运行，不证明工艺检出能力。未上传真实数据、生成数据或模型权重。

本入口不会自动使对齐器的 `accepted_for_training=false` 变成团队签收；返回 receipt 的 `review_claims_verified=false`、`scope=experimental_only`、`deployment_authorized=false`。本轮仍未实现真实标签内容审查、融合模型可信保存/加载及线上部署绑定，也未开启物理 R-03。
