# D07 实验指标与执行台账定义

2026年11月23日由 D 确定统计实现口径。正式三组工艺对照的联合冻结目标日为11月24日；本文件不会替 A/B/C 作签收，也不把计划行当已运行数据。

| 项目 | 固定定义与失败处理 |
| --- | --- |
| 主要指标 | 在预定模拟期限内达到 A 的目标、满足规定安全约束的有效启动 episode 数 / 全部有效启动 episode 数。执行失败、超时、未恢复都计失败。 |
| 效率 | 配对工况、初态、种子、控制预算下的模拟任务 makespan。提升=(基线周期−四Agent周期)/基线周期。未达成任务不得从成功率分母消失；周期比较单列失败和删失，不把未达成的提前停止当成更高效率。 |
| 检测 | TP/(TP+FN)、TP/(TP+FP)、FP/(FP+TN)；分母为零记 null。人工传感器偏置、物理异常和候选动作越界分别统计。 |
| 检测时延 | 原始注入事件起点到首次在事件内报警的记录数。未检出与滑窗预热不可评分事件单列；不能只报告已检出事件平均时延。时间换算须有已核验采样周期。 |
| 整段正常误报 | 无注入的完整 episode 中至少出现一次误报的条数 / 全部无注入 episode。与正常滑窗误报率分别报告。 |
| 接管 | 风险探测调用开始、系统接管状态可观察、模拟操作确认提交、恢复状态可观察分别记录 UTC 和单调时间。模拟请求间隔不是实际人类思考时间。确认本身的 step 增量必须为0。 |
| 其他工艺指标 | 质量和能耗仅在模型有已核验变量及单位时计算；reward 与软件墙钟时间不替代质量、能耗或产能。 |

拟定三个工况（正常、传感器故障、过程扰动）、三个系统组，每个工况每组10条，共90条计划运行，使用30个配对条件种子。运行顺序种子261123固定；初始化学习种子17/29/43不与环境样本数相加。`l3_system.monitoring.experiment_readiness` 生成 `run_ledger.json`；每行初始状态为 planned、started=false，尚无任何性能结果。

现有 A 的 Atropine E-factor [12,15]、5步上限、连续2步达成是工程回归目标，不能转称已经批准的生产目标。提出60秒墙钟预算用于准备检查；与 B 实测预算尚未联合冻结。主研究 mAb 不共享 Atropine 目标、阈值与单位。

分集按源 episode/初态谱系；派生图像、文本、增强视图随源留在同一划分。标准化与 TF-IDF 只拟合训练；阈值只使用验证。测试集检查后保持评估记录，不再把它称为未查看保留集。独立性不能由不同种子自动推定。

只有损坏或不可读证据可单独标记不可计算，保留原始启动分母、运行ID、原因与文件哈希。不能排除失败、误报或慢运行来达到90%与20%。当前样本预算不是统计功效保证。

冻结门槛：实际可打开的目标、三组控制器、三类工况、资源与调度定义；固定软件、权重、变量和配置哈希；安全验收通过；来源和标签范围可核验。缺少任一项时保留阻塞原因。引用字符串和本地结构校验不等于真实人员签名。
