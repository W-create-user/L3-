## 方法与实验口径

HTN 由 A 拆解和排序，CNP 在当前可用集合竞价，B 执行仿真动作，D 审核。资源实验沿用现有 CNP 的评分 `0.5 × 能力适配度 + 0.3 / (1 + 估计成本) + 0.2 × (1 - 负载)`。权重沿用仓库默认值，分数取六位小数，同分按 ID 排序。无负载组将剩余两个权重重新归一化。固定组以相同的候选过滤和锁规则按 worker ID 排序。估计成本为任务基准耗时乘 worker 耗时系数。负载来自每个输入预生成的背景负载序列。忙碌、离线、心跳过期、能力不符的 worker 不参与本次授予。

赋予 `assignment_id`、`attempt` 与租约截止 tick。反馈核对任务、worker 和尝试号，同一终态回执重复返回原结果。租约到期停派且保留锁，对账证实原动作未执行后才允许重授。故障夹具在预定完成 tick 原子提交，退出导致尚未提交的任务由夹具所有者确认撤销。真实执行结果未知时不得用该仿真前提推定未执行。

一次工况和种子组合的任务序列、资源参数、故障事件与负载在三组内相同。每个逻辑 worker 的容量为一。记录 10 个配对种子/工况，文件内用输入 SHA-256 关联各组。makespan 为最后完成 tick 减首任务到达 tick，达到上限时保留未完成状态。初次排队等待为到达至首次授予，未分配者按截止 tick 计。利用率为累计忙碌 worker-tick 除以可用 worker-tick，超时率的分母为授予数。竞争次数统计有能力候选被占用的投标尝试，因同一任务可等待多轮而可能重复计数。重叠授予单列。统计均以仿真 tick 计。

## 协议与恢复

正常路径为 A → C 分配，A → D 审核，A → B 执行，B → A 返回执行序号。各轮检查角色、`correlation_id`、动作和预期步进序号。B 夹具对已成功的相同请求返回原回执，对冲突请求和过时步进序号拒绝。D 拒绝时计数保持不变。C 退出后心跳超过 100 ms，A 进入停派，随后发起的 B 请求被阻止，B 报告计数仍是 1。C 重启、回探确认后 A 恢复，重新分配和审核的一轮将计数从 1 增至 2。

通信使用 Linux 本机 IPv4 回环，libzmq 4.3.5，REQ/REP，JSON 单帧 16 KiB 上限，发送和接收均限时。进程间回执依赖应用层去重；缓存保存在当前 B 进程中。夹具没有鉴权、持久执行账本和真实环境步进，B 失联或执行结果未知时需要另行对账。

## 协同学习

合成系统两维状态，有交叉耦合。actor 0 仅见本单元的状态 0 并输出动作 0，actor 1 对应状态和动作 1。动作范围 `[-1,1]`，两者共用奖励 `-(||下一状态||² + 0.06 ||已执行动作||²)`，量均无量纲。集中 critic 训练时看联合状态和联合动作，各 actor 推理仅看本地标量。两个 actor、两个 critic 各有单层 24 单元的 tanh 隐藏层，目标网络软更新率 0.02，折扣 0.95，批量 64，回放容量 4,096，探索噪声标准差 0.12。20 步时间截断继续 bootstrap，拒绝不产生转移。六个候选由两档 actor 学习率和三独立训练种子构成，每候选 140 回合、2,800 次模拟步及 2,737 次更新。日志含失败或未入选候选、各轮训练曲线、请求动作和执行动作。

以六个公开验证种子选学习率和权重，选中 `7102/0.002`。复载的验证回报在绝对误差 `1e-12` 下吻合。所选权重 SHA-256 为 `577f457e0fb252916264c0bb674569854a7782e026489afb201d97a868bde602`。六个独立夹具评估种子的平均回报为固定零动作 −2.8063、共享比例增益 −0.4248、MADDPG −0.7965。学习策略落后于比例控制，故冻结为研究样本。一次越界拒绝步进计数为零。B 的 `68831ef9e06440a1066e9d18bfb3955e1ac3006f` 中 `JointActionResearchEnv` 仍明确禁用训练，本模型未走 B 的网关或 D 的正式审核。
