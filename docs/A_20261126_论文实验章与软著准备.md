# A09 论文实验章草稿与软著材料准备

2026 年 11 月 26 日。暂拟题目：面向流程工业 L3 仿真的四智能体编排与缓冲液位配对验证。

## 实验方法

采用 SMPL MAbEnvGym 缓冲罐液位恢复任务。设定带为 [14.95, 15.05] dm；每步代表 60 仿真分钟。首个连续三次有效 post-step 真值落在设定带内的步次为达成时点。评分读取未裁剪的模型状态。按条件配对环境初始内部状态、动作预算、结束条件及模型审核。

三类工况各 10 个公开可重复条件。正常和传感器偏置工况的初态偏移为 ±0.03 dm；传感器偏置在前三次控制预测的投递值上叠加 +0.10 dm。初态扰动工况的正负偏移幅度为 0.15–0.30 dm。偏置只作用于控制器测量；初态扰动用于研究恢复，持续过程扰动留待独立试验。

观测器在模型重置时使用经校准的起始液位，以审核通过且执行完成的动作和模型流量关系传播液位估计，并对投递测量作残差检查。后续评分真值和偏置标签留在实验评价侧。对照包含传统比例、研究 PI、单 Agent 观测器和四 Agent 观测器。单 Agent 与四 Agent 使用同一观测器及一个执行资源。开发运行使用 B 版脚本的原预算定义，正式协议的墙钟起点、可信证书和回执防护仍须在运行器独立核验。

## 结果与讨论

D 在 11 月 24 日的 90 次配对仿真中，三组均为 30/30，平均周期各 240 仿真分钟，周期缩短 0%。设定保持三步决定了理论最快为 180 仿真分钟。[D 组原汇总](../evidence/d_20261124/mab_comparison_summary.json)

11 月 26 日，A 独立复跑 B 的四臂开发试验 120 次，共审计 420 个模型步。比例组与 PI 组平均各 240 仿真分钟；单 Agent 与四 Agent 观测器组各 180 分钟。四组均为 30/30。两种观测器路径相对传统比例组的平均周期缩短 25%，两路径之间保持 0%，30 对执行动作序列相同。可将本组改善归到观测器控制策略的变化，项目要求的协同提效仍缺证据。[A 开发汇总](../evidence/a_20261126/development_replication_summary.json)

已公开开发条件用于实现和复跑核对，模型、可信起点和单资源设计限制了结论适用范围。正式盲测以另行冻结的方案估计成功率与配对区间，C 的动态多资源调度以吞吐、冲突和节点失效另立实验。论文生产安全与持续过程扰动、能耗、跨工序产出部分待证据；物理阈值、现场模态资料和数据许可待确认。[正式评估口径](A_20261126_冻结决议与开发对照.md)
