## Windows VS Code 复现

在仓库根目录打开终端，使用已有虚拟环境：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s l3_system/tests -t . -v
.\.venv\Scripts\python.exe -m experiments.verify_a_console --output outputs/a23-console-check
.\.venv\Scripts\python.exe -m l3_system.ui.app --output-dir outputs/a23-console --goal-spec configs/goals/atropine_goal_regression.json --goal-registry configs/goals/atropine_model_registry.json
```

打开 http://127.0.0.1:5000。已运行过的会话可以请求暂停、修订目标、确认接管，然后在恢复时选中“明确开始新仿真回合”，再运行数值目标。每次验证用新的输出目录。核对 A_events.jsonl（验证脚本）或 events.jsonl（控制台）中的任务和操作记录。

mAb 在隔离副本中原样载入 db7fbe4 的 l3_system/execution，从 dd76cea 载入原版配置和字典，并按该版本的补丁安装 MPCTools。分别用 1611 和 1612 运行以下命令，每次换用新的输出目录：

```sh
python -m experiments.verify_a_mab_goal --registry configs/environments/mab_physical_registry.json --b-config configs/controllers/mab_buffer_pi.json --pi-seed 1611 --output outputs/a23-mab-1611
```

验证器写入 summary.json 或 result.json 及对应日志。Git 父提交保留本轮改动前的代码，报告中的固定 B、D 版本可追溯已使用的输入。
