# D03 孤立森林训练与统计 R03

本轮已实际运行合成夹具训练，保存Isolation Forest、训练集标准化器、验证阈值和模型卡，并测试保存加载一致性。合成夹具有6个正常训练episode、4个验证episode、4个测试episode，每个40条39维观测；异常由生成器标注，不能作为Atropine过程检测效果。本轮没有把B已有接口通过记录自动标成工艺正常训练数据。

训练工具：`python deliverables/D01/scripts/train_isolation_forest.py --synthetic-demo --output LOCAL_NEW_MODEL`。输出目录必须不存在。实际数据使用 `--episodes LOCAL_EPISODES.json --label-scope sensor_fault` 或 `process_anomaly`；必须逐episode提供episode_id、lineage_group、split、observations、labels、label_source、label_scope。labels每条必须为明确布尔值，不接受null；来源与分组声明仍需人工核实。

特征为单一episode内滑窗的均值、标准差、最小值、最大值、首末差、平均绝对逐步差。标准化只拟合正常训练集；IsolationForest使用100棵树、固定种子、contamination=auto。正常与异常验证窗口按F1选择阈值，同分取较高阈值，测试数据不参与选择。异常窗口指窗口内至少一条已标异常样本；相关窗口不能作为同等数量的独立样本。

模型卡保存三个集合的episode列表、软件版本、阈值来源、逐episode混淆矩阵和首个事件的记录延时。首事件漏检和episode内所有异常均未检出分别保留；没有检测到的事件不记零延时。延时单位为记录，不是秒；这不是完整多事件恢复统计或D08最终报告。

可选StatisticalMonitoringAgent在既有D审核通过之后，使用可信window_provider提供的完整最新窗口评分。窗口不足、与当前观测不一致、推理失败或异常分数超过验证阈值时以R-03-STAT拒绝。它不能推翻R-01/R-02或已配置确定性R-03的拒绝。必须显式enable_experimental=True，不默认接入主链。恢复确认后下一动作仍重新审核；完整置信度融合、保持时间和D05策略尚待实现。

统计R-03是经验异常围栏，不是已确认的化学安全阈值。score不是概率，合成数据权重不宜直接用于工艺控制；本轮没有启用现场或真实工艺规则。实际模型需以B05独立正常依据、异常标签和来源分组重新训练验证。

模型保存在model.pkl与model_card.json。只允许用load_trusted读取本机可信训练流程产生的文件；pickle具有执行能力，哈希一致也不能证明不可信来源安全。跨sklearn版本加载会拒绝。权重和真实数值训练数据不随本次代码提交上传GitHub；可在本地用固定生成器重现合成训练。

本轮新增9项训练/接口测试，D01测试共129项；另运行既有系统回归。检查覆盖正常训练限制、来源组跨集拒绝、测试集不影响阈值/标准化、标签域隔离、保存加载、特征维度和硬规则优先级。结果只证明工程链可运行，正式工艺效果未验收。
