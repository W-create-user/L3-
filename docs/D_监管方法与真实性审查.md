# D 监管方法与真实性审查

本文可作为论文或结题材料中D监管部分的基础文本。所有结果对应仿真与人工传感器偏置，不涉及企业现场健康标签、真实操作员研究或工业安全认证。

## 方法

监管先检查观测完整性、动作格式及动作范围，再检查版本化模型规则、数据新鲜度和学习模型适用范围。任何学习分数或人工确认都不能覆盖确定性拒绝。候选动作由B执行器以请求和状态版本绑定后执行，未知结果不自动重试。

传感器偏置模型使用4步因果窗口，提取当前E-factor相对稳态参考的比值统计。正常训练轨迹拟合标准化和100树孤立森林；将孤立森林异常分数与训练尺度归一的参考残差组合。独立的验证源组用于isotonic标签概率校准，另一组验证源用于零误报约束下的阈值选择。标签由预先登记的送达观测副本注入产生，不来自模型分数、奖励或阈值。

三级干预输出分别对应受限采样、可提交动作门禁复核和请求接管。概率只估计该数据分布下的人工传感器偏置窗口标签，不解释为工艺安全概率。恢复需要明确操作记录和连续有效历史；同一观测重复读取不累计恢复。仿真停止后若没有新的可信过程样本，采用明确的新episode流程，不凭空产生“恢复观测”。

三模态模型采用ResNet18、LSTM、TF-IDF及独立朴素贝叶斯文本基线；比较拼接、注意力、单模态与去模态模型。视觉主干使用官方ImageNet权重且冻结，训练小头。图像与文本由同一数值历史生成，显式报告同源性，不能声称新增独立现场视觉感知。

## 受检结果

最终新保留测试包含12条episode、720次真实Atropine step，形成684个相关窗口。窗口混淆矩阵为TP96、FP0、FN0、TN588；6个注入事件均检出；6条完整正常episode均未报警。前两版未通过工程标准的结果保留。模型仅对训练及验证作拟合；最终保留集在冻结后评价一次。

21个三模态对照模型实际训练，各20轮、3个初始化种子。验证输出在持久化恢复后逐值一致，但测试误报及种子敏感性仍明显，现有结果不支持稳定优越性结论。

真实模型与HTTP联合验收记录29个接口检查和16次Atropine step，确认零step、重复请求阻断、硬规则优先及终止后阻断。另完成mAb模型围栏6个检查和3次真实step。全新Python环境通过503项单元/契约检查，最终传感器模型重新训练后的文件哈希一致。

## 必须保留的局限

窗口相关、源工况覆盖有限，数据源组的统计独立和现场代表性未建立。校准诊断和区间均不构成总体可靠度保证。人工传感器偏置不等于物理异常；数值图像不等于摄像头；模型自身边界不等于工厂危害阈值；软件调用耗时不等于生产效率；测试通过不等于达到项目90%成功率或20%效率目标。

浏览器验证受环境访问限制，未完成浏览器实录。没有真实志愿者、论文公开发表证明、软著授权证明或独立复核签字，不得补写这些状态。

## 真实性审查清单

| 拟写结论 | 审查结论 |
| --- | --- |
| 已完成固定预算的学习模型训练 | 有训练配置、权重、损失、划分与恢复记录，可写。 |
| 本轮新传感器基准达到事先登记的工程标准 | 有锁定配置及最终保留测试，可限定范围写；须同时披露前两版失败。 |
| 已证明总体检出率100%或广泛泛化 | 小样本与工况不足，不可写。 |
| 已实现三级仿真监管和人工确认接口 | 有HTTP及真实模型日志，可写；浏览器实录仍缺。 |
| 融合显著优于单模态 | 当前结果不支持，不可写。 |
| 已验收mAb物理安全联锁 | 只有模型围栏与单位检查，不可写。 |
| 已达到全项目生产成功率和效率目标 | 没有完整生产对照证据，不可写。 |
| 已发表论文或取得授权 | 没有外部凭证，不可写。 |
