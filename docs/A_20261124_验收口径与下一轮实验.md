## 1. 环境、任务和期限

主研究环境定为 SMPL MAbEnvGym；Atropine 用于软件回归、监管与接管验证。首个可复现的验收子任务是恢复并保持 mAb 模型缓冲罐液位。项目级生产验收还需经过核验的产出对象、合格质量条件、工况与安全限值，目前无足够依据定义这些字段。液位达标、动作在模型边界内和真实生产验收分别登记。

| 字段 | 首项仿真验收任务的冻结建议 |
|---|---|
| 目标变量 | 模型观测索引 17，按 B 的坐标映射以 dm 评价。控制器仅获取试验声明的投递测量，D 侧真值用于评分。 |
| 成功判据 | 连续 3 个已执行有效 post-step 样本均在闭区间 [14.95, 15.05] dm，且满足冻结版仿真审核条件。未执行的新样本、重复状态、初始化和重放状态不得充数。 |
| 运行期限 | 不晚于第 10 个仿真 step 完成，另设 90 秒墙钟预算；任一预算耗尽未达标即失败。每步 60 仿真分钟，仿真上限 600 分钟。 |
| 主成功率 | 达成 episode / 全部有效启动 episode，超时、求解失败、未恢复、安全失败均计失败。说明未启动数和原因，同时报告达成数 / 计划数。目标为至少 90%，报告分子分母、分工况及区间。 |
| 样本 | 先做开发与故障冒烟，再冻结版本。在新保留组中每工况 10 个配对条件，共 30 个条件。既有种子 26001–26030 只作回归与开发对照。 |
| 项目排期 | 按总计划 24 日候选冻结、25–27 日对照和整理、28 日功能冻结、29 日独立复现与导师复核、30 日逐项登记。条件未达到时登记阻塞或未达标。 |

三类工况沿用 D 冻结的定义和量级。正常与传感器偏置的初始液位偏移在 ±0.03 dm。偏置仅在前 3 次控制器预测的测量中加入 +0.10 dm。初态扰动设置正负偏移，幅度 0.15–0.30 dm，属于初态扰动，持续过程扰动另立试验。配对时同一条件的初始内部状态、源模型、扰动注入、动作预算、审核、终止条件一致。训练、调参和保留评估按来源 episode 分开。运行前固定代码 SHA、配置、种子、顺序、控制器/权重、资源表、原始记录位置和失败码。

## 2. 效率口径和现有结果

主要比较为四智能体候选与冻结的传统控制基线。传统基线沿用 D07 的比例控制器，固定 B 执行接口及 D 模型审核，不经 A/C。单智能体候选为归因对照，启用同版新控制器与审核，不经 A/C。预先声明的主指标是配对仿真时间缩短比例：

**效率提升 = (基线配对平均仿真分钟 − 候选配对平均仿真分钟) ÷ 基线配对平均仿真分钟 × 100%。**

从有效启动计到首次满足连续三步判据，算上取得达成所需的最后一步。两组共同成功的配对计算周期，并报告共同成功覆盖率、配对区间、失败和未启动明细。另报告覆盖所有预定配对的限期敏感性分析：失败或未启动按 600 分钟惩罚，明确标记为统计处理而非实际运行时间。共同成功结果与敏感性结果需要同时呈报。运行前冻结按工况分层的配对重采样方案；种子本身不证明样本独立。试验中若成功率下降或出现新增安全失效，周期缩短不能单独支持通过。20% 为工程目标，置信区间跨越目标时注明证据不足。软件墙钟、CPU 开销另列。

从 [D 的公开汇总](../evidence/d_20261124/mab_comparison_summary.json) 复核，三组各 30/30。每组正常和初态扰动各 10 次，全部为 3 步；偏置 10 次，全部为 6 步。每组平均 4 步即 240 分钟，现有提升为 0%。由于三步保持的下限是 180 分钟，以这组基线推算，理论上限为 25%；达到 20% 要将均值降至 192 分钟或以下。对基线均值仍为四步的 30 个完整配对，这相当于总步数最多 96 步。这个推算用于决定开发优先级，新保留数据的基线仍须按预注册方案重新测量。

## 3. 下一轮控制与调度

| 负责人 | 实施内容与交件 |
|---|---|
| B 控制与执行 | 第一优先做抗测量偏置候选。以现有比例控制为冻结基线，开发基于控制器可见历史和模型残差的偏置估计/补偿，与原 P、研究 PI 在开发集比较。禁止使用注入标签、消失时刻或 D 评分真值作为控制输入。量测不可辨识、求解失败或状态超域时走现有审核和接管路径。提交控制器 SHA、观测权限、动作范围、适用条件、关闭/回退配置。现有源 MPC 是混合研究方案，若使用须单列其改变的动作与控制边界。 |
| C 调度与通信 | 第二优先做固定控制律的等资源调度对照。先给出实际可用的资源、能力及任务依赖图，并接通 ZeroMQ、租约与回收。对同一耦合 mAb 环境，多个执行提议者使用 B 的联合动作网关，只有网关推进模型。使用相同资源和控制律，对比固定分配与动态调度，在任务冲突、节点退出、迟到反馈下验证。多 episode 的并行吞吐单列为调度指标，不能抵扣单 episode 仿真分钟。 |
| A 组合与发布 | 先验证本地基线、唯一推进、消息关联、拒绝、超时、未知动作与恢复，再固定三组系统。增加同一新控制器下的单 Agent 与四 Agent 对照，识别改善源自控制还是编排。缺少 C 多资源链路时，公开结果只标作单资源控制对照。 |
| D 安全与统计 | 直接从对应提交读取与运行三组代码，复核盲测访问权限、配对相等性、拒绝/重复请求/人工恢复与失败保留，计算成功率、仿真周期和区间。先登记安全门禁结果再运行正式保留组。 |

运行清单冻结前先确认：候选控制策略已实际成型，模型审核配置可获取，候选与基线条件等价，所有晚到或再次提交的动作都不能额外推进。如果控制改进与调度改进一起启用，附同控制器、同资源对照，以支撑对来源的归因。既有 90 次同控制律结果保留为基线回归，不再用相同设计论证效率提升。

## 4. 正式验收所需的确认凭证

| 事项 | 确认与记录 |
|---|---|
| mAb 物理安全 | 导师与工艺负责人确认来源文件、版本、变量坐标/单位、适用工况、阈值和审批记录。B 核对变量及动作映射，D 复核审核规则。当前保留模型边界与实验范围。 |
| 独立现场图像、日志与许可 | 资料权利方确认采集来源、许可范围、用途、保留和发布边界。D 核查独立模态与标签来源，合成和派生结果单列。 |
| 独立复核与浏览器实录 | 由未参与本轮实现和调参的人按固定 SHA 在有权限的浏览器环境复跑网页接管。保存步骤、结果和证据位置。D 的 HTTP/真实仿真证据继续作为已完成项。 |
| 论文与软著 | 分别记录稿件进度、真实投稿/发表凭证、申请受理与授权凭证。状态依据实际凭证更新。 |

联合冻结记录应包含 A/B/C/D 的具名确认与证据链接，导师的工艺和数据核验另附。未获确认的生产、安全、数据和成果条目继续登记为待验收。
