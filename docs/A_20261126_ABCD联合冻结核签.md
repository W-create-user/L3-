## 本轮范围

首轮限于同机同步、单一执行资源的 SMPL MAbEnvGym 缓冲液位配对实验。三臂为传统 P、单 Agent 观测器、四 Agent 观测器。后两臂使用同一控制器和一个执行资源，四 Agent 路径经过 A 与 C 本地编排，三臂共用模型审核。学习门控留在单独的试验方案；跨进程通信、ZeroMQ、多资源动态调度、学习门控联合验证和生产安全验收继续登记为待验证。

成功要求 [14.95, 15.05] dm 范围内连续三个有效步后样本，使用未裁剪真值评分。最多 10 步，每步 60 仿真分钟，墙钟从环境构建前计 90 秒。主指标比较四 Agent 与单 Agent 的配对周期和成功率，传统 P 用于估计控制策略收益。公开开发集的 25% 改善相对传统 P，正式达标凭保留组结果判定。
