# D04 三模态因果对齐与缺失接口

本轮实现时序、视觉和文本的因果对齐索引及缺失mask，作为D04编码/融合的数据入口。没有训练ResNet、LSTM、文本分类器或融合模型，也没有取得新的现场视觉数据。测试中的二进制视觉文件是资产选择夹具，不是用于图像解码的真实图片。

入口为 `python -m l3_system.monitoring.multimodal_alignment --manifest LOCAL_MANIFEST.json --root LOCAL_DATA --output LOCAL_INDEX_NEW.json`。所有LOCAL路径由本地交付提供；输出包含数值观测，只保存在本地，不能因此自动发布到远程仓库。已有输出不会被覆盖。

## 数据契约

D04Alignment/0.1顶层包含schema_version、environment=Atropine、observation_size=39、binding、binding_sha256、max_lag_records及episodes。binding沿用D03的AnomalyBinding/1.0，包括有序变量、单位、坐标和环境配置；指纹必须与声明一致，生成索引继续保留它。该检查证明声明未被静默改变，不证明现场单位或来源真实；后续训练/部署须与可信配置的期望绑定比较。v0.1不接受mAb直接套用。

max_lag_records按visual和text分别给非负整数预算，单位为交互记录，不是物理秒。记录映射必须由采集方提供；本工具不推断相机/文本时钟，也不证明跨设备同步。

每个episode包含episode_id、lineage_group、split、series、visual、text。series每行仅允许record_index及39维有限数值observation，编号从0连续。时序是本版必需输入，缺失时拒绝；不假造零状态继续运行。视觉、文本缺失时显式给空列表。

每个视觉/文本资产需要以下字段：

| 字段 | 语义 |
|---|---|
| path、sha256 | 数据根目录内的文件及真实哈希；拒绝越出根目录和文件篡改 |
| record_index | 资产对应的观测记录编号 |
| available_at_record | 资产实际可以被消费的记录；不得早于record_index |
| source_start_record、source_end_record | 生成资产使用的数值/事件范围；末端不得晚于资产对应记录 |
| source_kind | native_simulation、authorized_external、derived或synthetic，按真实来源填写 |
| derived_from | 派生/合成资产必须恰好指向当前episode，禁止跨episode隐含派生 |
| generator_version | 生成器或采集导出器版本 |
| leakage_reviewed_by | 内容泄漏审核声明；不能以填字段代替实际审核 |
| input_role | 固定causal_input，不把标签文件作为模型输入 |

模型仿真输出的趋势图应标derived，项目生成的示意图或文本应保留synthetic/derived身份；不能因为它们在视觉文件中就标成现场原生感知。工具检查文件存在、身份和因果声明，不会解码图片、理解文本或自动发现图中写入的故障类别，后续还需内容抽查和编码器文件格式校验。

## 对齐规则

对每条时序记录，只考虑record_index和available_at_record都不晚于当前记录、且未超出相应lag预算的资产，按对应记录及可用时间选择最近一项。未来帧不会提前使用，晚到帧只能在已经可用且未过期时使用。同一模态相同记录/可用时刻的多资产会拒绝，多相机融合需另行版本化，不任意挑一个掩盖歧义。

输出固定模态顺序为timeseries、visual、text。modality_mask为三个布尔值：时序必为true，缺失视觉或文本为false，同时相应资产索引为null。没有用异常标签或真值图补齐缺失模态，也没有生成伪造特征向量。

## 来源与泄漏

来源组跨train/validation/test会被拒绝；同一数值序列、同一资产内容或路径也不能跨集合复用。完全相同数值序列的整数/浮点表示不会绕过检查。仍需人工审查近重复轨迹、实际来源关系和图像/文本内的标签泄漏；哈希不能发现视觉近重复。

索引里的episode_id、lineage_group、split、record_index、文件路径及来源声明仅为追踪元数据，不应直接当作分类特征。后续编码器只消费规定的观测和资产内容；标签单独传递，不从文件名、D拒绝理由或未来日志提取真值。

本次不生成训练标签、不自动分集，accepted_for_training=false。全模态索引齐全也不自动表示已经取得可用的正常/异常研究数据。

## 验证与后续

新增20项测试覆盖精确/延迟/未来对齐、缺失mask、同源与同内容跨集、未来派生、源绑定变化、目录边界、哈希、标签误用、多视图歧义、输入不可变和本地CLI。D01测试177项，系统回归124项；实际视觉/文本内容与学习效果未验收。

下一步D04可在真实可追溯模态到位后实现编码器，保留单模态、拼接、注意力和缺失模态消融。当前接口不能替代原任务要求的三支实际模型和融合训练证据。
