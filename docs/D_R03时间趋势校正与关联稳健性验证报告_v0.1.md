# D模块 R-03 时间趋势校正与关联稳健性验证报告 v0.1

## 1. 研究目的

检验前期观察到的高相关性是否主要由共同时间趋势造成。

## 2. 分析方法

1. 原始数据相关性。
2. 线性时间去趋势残差相关性。
3. 一阶差分相关性。

Pearson与Spearman分别计算。

## 4. 结果解释原则

- 原始相关性高，不代表存在直接工艺关系。
- 去趋势后仍然相关，可作为进一步研究线索。
- 一阶差分相关性可辅助判断短期变化是否同步。
- 去趋势和差分结果不一致时，需要谨慎解释。
- 一阶差分可能放大观测噪声。
- 线性去趋势不能消除所有非线性时间依赖。
- P4只有10个观测点，差分后只有9个观测点。
- 本分析不建立危险标签或工业安全阈值。
