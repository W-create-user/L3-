## 2. 输入输出契约：Atropine 与 mAb 分开

| 项目 | Atropine | mAb |
|---|---|---|
| 基础观测 | 完整有限数值向量 `(39,)`，normalize=false；按固定布局提供，不自行物理反归一化 | 完整有限数值向量 `(1970,)`，`physical_divided_by_xscale`，不要把物理向量混作模型坐标 |
| 候选动作 | `(4,)`，以 live adapter 的空间/uss_subtracted 配置为准 | `(9,)`，`physical_divided_by_uscale`，执行前由 B 映射/校验 |
| 关键变量 | obs[5] E_reference、obs[6] E_current，dimensionless、model_observation_normalize_false | obs[17] 模型缓冲液位；冻结版本 xscale[17]=3，因此 h_dm=obs[17]×3；动作7是出口控制，具体单位及其余轴按 B 固定字典 |
| D05 残差历史 | 恰好4个连续已执行 post-step、同 episode 的 raw39；obs[5]>0。模型仅提取5/6比值特征；启动时不足4条不能补抄状态 | 当前无匹配模型，返回不可用/未知，不能把1970压成39或套 Atropine 阈值 |
| D04 Batch | `series[N,T,39]`（本产物 T=4）、`images[N,3,32,32]` RGB float、`texts[N]`、bool mask[N,3]；列序 time/image/text；labels[N]仅用于 Batch 校验与离线评价，不作为推理特征 | 无对应训练产物，阻塞 |
| D04 具体配方 | 此产物 series 第0列固定零、其余38列保持来源坐标；图像/文本由4步数值派生，配方见 sensor_fusion_data.py。训练统计固定，推理不重新 fit | 不适用 |
| 语义绑定 | environment、按序变量名/单位/坐标、采集配置哈希；残差模型另固定控制器与 adapter SHA | 运行前固定 B 数据字典、xscale/uscale、模型与配置哈希；仅形状相同不算绑定通过 |

完整有名绑定见 `binding.py::make_binding` 和 `observation_window.py::ObservationWindow`。窗口包为 `{binding, episode_id, state_versions, values}`，gate-time trusted context 为 `{binding, episode_id, state_version}`；必须由 B 实时状态提供并用 `check_window` 核验。窗口收集器的最后值不能冒充权威 live context。模型 `score()` 原生不包含此检查，接线方必须调用。缺失值显式 mask/null，不能静默零填后把预测当有效。

`MonitoringAgent.check_request` 的当前返回：

```json
{"request_id":"one","subtask_id":"control","task_id":"B08-smoke",
 "decision":"pass","rule_id":null,"reason":"...","risk_level":0,"demo_mode":false}
```

拒绝时 decision=reject、risk_level=3、rule_id 为 R-01/R-02/STATE-INVALID/具体 R-03；启用规则时可附 `basis/suggestion/rule_version/environment/violations`。`approved/status/level/intervention` 是 `check_action` 的字段，**不是** `check_request` 的固定字段，不能混读。request/subtask 原样关联不是鉴权或去重凭证。

D05 返回 `schema_version=D05RiskAdvisory/0.2`、`risk_level/mode/automatic_execution_blocked/execution_authorized/requires_action_gate/reason/clean_observations/review_acknowledged/review/episode_id/state_version/confidence_probability`。level1=request_review（只允许请求硬门控审核）；level2=restricted（禁止自动执行）；level3=takeover_requested（禁止自动执行并请求接管）；execution_authorized 永远 false，confidence_probability 为 null。基础门控的 level0 与 D05 的 level1 分属两个契约，不应强行共用枚举。

错误处置：缺失/非有限/单位或绑定不符/窗口过期或重复/模型异常/超时，学习监管链都不得回退成“正常”。记录 reason 与 request/episode/version，停止本次推进并请求复核；不得把迟到 pass 用于后续状态。`RiskPolicy.evaluate` 的非法证据会锁存并抛异常；调用方必须捕获并映射拒绝。基础 MonitoringAgent 不自带推理计时器、远程服务或线程取消；必须在唯一网关外的工作进程实施期限，网关在最终执行前重查状态与截止时间。单纯 future timeout 不能保证取消底层工作，迟到结果必须丢弃。
