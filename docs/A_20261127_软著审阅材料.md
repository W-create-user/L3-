# 软著审阅与论文提交核对单

拟登记软件名称：流程工业四智能体仿真协同系统。版本与权利人由项目负责人核定。此件用于内部审阅，申请状态为待确认，正式提交、受理、授权分开登记。

## 技术说明与操作

软件接收仿真运行请求和可计算的目标，输出执行结果以及任务、授予、审核与接管日志。决策模块对目标拆解并校验依赖。执行链将审核结论与当前请求绑定，限制步进次数，异常后进入停派和接管。操作员通过本地 Flask 查看趋势、状态及计划，按“暂停 → 确认接管 → 填写操作人和原因并恢复”执行。完整输入约定、安装与复现见[发布手册](A_20261127_发布与验收.md)。

审阅用源码摘录可通过以下命令从当前工作树对应提交导出。该命令输出源码和运行说明供确认，不预设最终申请的代码页。

```bash
git archive --format=zip --output=A-source-review.zip HEAD l3_system/decision_agent.py l3_system/main.py l3_system/runtime.py l3_system/planning l3_system/ui docs/A_20261127_发布与验收.md
```
