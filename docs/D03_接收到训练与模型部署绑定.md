# D03 接收到训练与模型部署绑定

本轮将D01接收结果接入正常训练、验证阈值和冻结测试流程，并新增非测试模型的语义/时序身份校验。没有新增真实过程数据，没有把未确认标签改成真值，也没有默认启用统计或物理R-03。

## 正式输入转换

入口为deliverables/D01/scripts/train_from_intake.py，参数为--manifest、--root、--config、--dictionary、--labels、--output和可选--window-size。manifest、原始时序、配置和字典先通过D01结构、内容及哈希检查，再进行转换；输出目录必须不存在。

独立标签文件为D03Labels/1.0，至少包含scope（sensor_fault或process_anomaly）、alignment=observation_before、split_reviewed_by和episodes。episodes以完整episode_id为键，每项包含labels布尔列表、source_ref、normal_basis、reviewed_by。标签必须与每条动作前观测逐项对齐，不允许null、接口成功标签、缺省全正常或用动作后结果给动作前观测直接补标签。这里检查声明完整性及一致性，不能自动证明签字、来源或物理真值真实；仍需相应人员复核。

非excluded的episode必须有且仅有对应标签项。normal清单不能带异常真值，injected_anomaly清单不能全为正常。训练只使用iforest_train=true的训练episode；训练标签非正常仍由模型层拒绝。来源组和split原样保留，不按窗口重新分集；同源跨集和相同数值轨迹跨集拒绝，包括整数/浮点表示不同但数值相同的轨迹。

转换只取observation_before，不把reward、failure_reason、D判定或注入元信息作为特征。模型卡记录字典/配置身份、标签复核声明、三个集合的episode列表及模型版本。实际标签文件不应包含测试模型结果反推的真值。

旧train_isolation_forest.py的--synthetic-demo仍可用于工程检查。原始--episodes入口现在必须另加--allow-unreviewed-exploration，明确属于未通过接收桥的探索输入；它生成的无绑定非测试模型不能部署到StatisticalMonitoringAgent。正式过程训练应走上述接收入口，不能靠改label_scope名字升级合成模型性质。

## 模型与实际环境的绑定

AnomalyBinding/1.0包含environment、完整有序观测与动作条目的index/name/unit/coordinate，以及collection_config_sha256。训练时保存完整绑定和规范哈希。load_trusted可传expected_binding，拒绝同维度但变量名、顺序、单位、坐标或环境配置不同的模型；sklearn与numpy版本也必须匹配。pickle只加载可信训练输出，哈希或绑定不是不可信pickle的安全认证。

非synthetic_fixture模型必须有绑定；部署必须显式实验开启并提供可信trusted_context_provider和窗口provider。上下文含binding、episode_id、state_version；窗口包含binding、episode_id、state_versions、values。状态版本必须是非负、严格连续并结束于当前上下文版本，不能用重复观测伪造暖机。check_request还要求原始请求的state_version与可信当前状态一致；请求参数不能覆盖provider。

缺少历史时保守拒绝。B需通过已验证的安全采集或控制方案建立同episode真实历史，reset后清空并重新暖机；不能为凑窗口复制第一次观测。本轮未实现B的在线历史采集器，也不宣称完整v2消息信封已迁移或跨机器时钟已同步。可信provider与注册表的真实性仍是集成前提。

当前synthetic_fixture模型保留无绑定的显式测试路径，以兼容既有合成路由测试；不是生产豁免路径，不应用于实际工艺控制。

## 验证边界

新增10项接收桥和绑定测试，覆盖独立标签要求、对齐、来源覆盖、正常标签一致性、变量语义不符、episode/状态版本不符、整条接收到绑定训练，以及同数值轨迹的不同JSON数值表示。测试使用临时合成夹具；绑定部署中的固定通过分数仅用于验证路由，不估计模型效果。

本地D01测试145项、系统回归124项。真实B05标签、正常依据、来源组共同冻结仍待交付，本轮没有发布任何原始或派生数值轨迹、标签文件或模型权重。
