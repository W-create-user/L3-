# 面向流程工业仿真的层次化任务规划与四智能体执行验证

作者顺序、单位、通讯作者与资助编号由团队核实。本文为导师审阅版。

## 摘要

构建面向流程工业 L3 仿真的决策、调度、执行与审核系统，利用有限 HTN 表达工序依赖，使用合同网机制分配任务，通过动作回执绑定、模型审核和人工接管约束模型步进。在 SMPL Atropine 上验证了同步及本机 ZeroMQ 调用，在 MAbEnvGym 上对缓冲罐液位控制进行公开配对研究。120 次开发仿真中，传统 P 与研究 PI 平均各用时 240 仿真分钟，同观测器的单 Agent 与四 Agent 各用时 180 分钟，四组各 30/30 达标。观测器相对传统 P 缩短 25%，而多角色包装对同控制器的仿真完成周期未产生缩短。实验提供了模型范围内的可复现工程证据。正式保留组、生产效率与设备安全尚待评估。

关键词：层次化任务网络，合同网，模型仿真，配对实验，人工接管。

## 1 引言与相关工作

流程仿真中，动作的提议、审批、执行与反馈处理可能跨越不同模块。连接通信和运行链既要保持动作与状态一致，也要处理回包延迟及重复，避免对已执行或结果不明的动作再次步进。本文的问题是如何让任务分解、协调、模型执行和审核都可跟踪，并在同目标、同动作资源设置下估计控制器与多角色编排的各自影响。

HTN 将高层任务分解为满足约束的子任务，合同网协议提供发布、投标、授予和反馈机制。本文采用有限模板范围内的 HTN 和明确资质的 CNP 分配，并把可执行动作约束和结果处置作为独立机制。仿真使用固定版本的 SMPL 实现。[HTN 文献](https://aaai.org/papers/01123-aaai94-173-htn-planning-complexity-and-expressivity/) · [合同网文献](https://doi.org/10.1109/TC.1980.1675516) · [SMPL 源码](https://github.com/smpl-env/smpl/tree/c816917eebfde59d525e325b56d16db07e499531)

## 2 系统与方法

A 将目标表示为被控量、单位、区间、连续保持和限期，选择调整、保持或恢复路径。C 根据依赖与资源状态授予任务并关联终态反馈；B 保持唯一模型步进权；D 负责动作有效性和模型边界审核。只读步骤不推进模型。结果未知时保留待对账状态，只有具备可核对的既有回执或经人工处置才能恢复。Atropine 的跨进程实验采用本机 ZeroMQ，B 与 D 的审核和执行回执仍走原契约。Flask 操作台呈现状态与趋势，暂停及恢复经过后端状态机。

mAb 评价采用索引 17 液位的未裁剪模型值，成功要求连续三个实执行、有效步后状态位于 [14.95, 15.05] dm。每步代表 60 仿真分钟，限 10 步、90 秒。按工况与种子配对初态、扰动和限制。正常、前三次传感器投递测量带偏置、初始状态扰动各 10 对。观测器通过可信故障前重置值和已确认动作传播估计，使用投递测量作残差检查。比较传统 P、研究 PI、单 Agent 观测器与四 Agent 观测器。两种观测器使用同一控制律与一个执行资源。算法输出、授权回执和评分真值的访问范围见[预注册决议](A_20261126_冻结决议与开发对照.md)。

## 3 工程验证与比较结果

| 验证 | 观测结果 | 可支持的结论 |
|---|---|---|
| Atropine 本地及同机 ZeroMQ | 正常运行、拒绝、恢复和只读回归；回包迟到可核对既有步进，执行方退出保留锁并阻止恢复 | 支持所测协议与故障路径 |
| mAb 公开开发对照 | 传统 P、PI、单 Agent 观测器、四 Agent 观测器，四组各 30/30；平均 240、240、180、180 仿真分钟 | 观测器相对 P 缩短 25%，四 Agent 相对同观测器单 Agent 的缩短为 0% |
| C 逻辑多资源调度 | 三策略 90 次运行，1,260 任务完成，重叠授予 0。突发工况完整 CNP 的均值较固定分配长 0.2 tick | 当前逻辑场景未显示负载项稳定缩短工期 |
| 接管与审核 | 对执行拒绝、未知回执、恢复条件分别验证；真实模型执行回执不能靠重放恢复 | 可检查状态转移约束与无额外步进 |
| 多模态与学习消融 | D 在限定数据和缺失模式中做三模态对照；C 的独立合成学习夹具中 MADDPG 落后于比例策略 | 各自为探索性结果，联合真实生产评价待补 |

90% 指标登记达标数和计划/启动分母；正式效率以同控制器单 Agent 为对照，报共同成功覆盖率、失败限期敏感性和配对区间。开发组的同一批公开条件不作为正式独立估计。HTN、CNP、多模态和人工接管目前在不同证据中独立检查，完整同批消融保留待做。效应解释、原始数据复算和固定入口分别见 [A 开发复跑摘要](../evidence/a_20261126/development_replication_summary.json)、[C 调度方法](../deliverables/C08/README.md)、[D 局限与证据](D_持续交付与验收边界.md)。

## 4 局限与结论

范围限于固定 SMPL 仿真、可信标定、一个 mAb 执行资源及实验审核规则。模拟液位达标不足以衡量产品质量、产能、能耗或现场安全。跨工序生产目标、现场数据授权、跨进程 mAb、执行方永久失联后的持久对账和正式保留组仍需独立验证。结果支持现阶段使用观测器并检验多角色系统的动作和回执约束。计划中的 20% 协同提效目前缺少达标证据。[运行复现与证据入口](A_20261127_发布与验收.md)
