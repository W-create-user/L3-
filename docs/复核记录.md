# 本轮复核记录

基于已合并的四智能体原型继续检查，修复以下问题并补齐中期实验入口。

| 问题 | 修复与覆盖 |
|---|---|
| 旧终态反馈可能释放同一角色的新任务锁 | 重复终态幂等，冲突终态拒绝；释放锁前检查锁所属任务 |
| 只完成一个子任务就把父任务依赖视为完成 | 父任务需全部已注册子任务完成才满足依赖 |
| 分配查询缺少父任务身份校验 | 当前分配、活动分配、历史查询统一检查父任务 |
| ready_tasks 返回可修改的内部引用 | 返回深拷贝，调用者不能改写内部依赖 |
| CNP 接受 NaN/Inf 成本、非法权重和空身份 | 数值有限性、布尔值、非空字符串校验；拒绝空权重配置 |
| 环境提前结束但汇总仍显示最后一轮完成 | 汇总标记 incomplete_or_failed，保留各轮独立状态与原因 |
| 同步 B 返回 running 可能遗留锁或误报完成 | 同步链只接受终态结果，非法结果转失败并清理候选和锁 |
| 主验收脚本使用 assert，优化模式可能跳过检查 | 改为显式 RuntimeError 检查，并在 python -O 下实际运行 |

验证结果：74 项单元/契约/故障注入测试通过；10 个真实 SMPL 验收场景通过；三个控制臂各三个种子的配对实验通过；40 个离线动作门控样本完成比较。依赖检查和文档本地文件链接检查通过。原始日志、配置、源哈希、CSV 与图表位于 `evidence/review/`。

GitHub Actions 新增 Python 3.11/3.12 的测试与 Python 3.12 的真实仿真/对照任务。远端任务是否通过应以 PR Checks/Actions 显示为准，本地通过不自动代表远端通过。
