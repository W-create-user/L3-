
# D模块 R-03 状态异常监管规则设计 v0.1

## 1. 设计目标

基于 AtropineEnv 的 39 维 observation，
建立仿真过程状态异常监测机制。

## 2. 数据来源

- observation_schema.json
- observation_samples.json
- B提供的真实环境源码
- 后续正常及异常工况运行日志

## 3. 第一批重点监测变量

| 索引 | 变量 | 监测方向 |
|---|---|---|
| 5 | E_factor_steady | 基准参考 |
| 6 | E_factor_current | 当前变化 |
| 7 | estimator_x_1 | 状态变化研究 |
| 8 | estimator_x_2 | 状态变化研究 |
| 37 | Q_organic | 有机相流量 |
| 38 | Q_aqueous | 水相流量 |

## 4. 规则设计

R-03-01：观测数据合法性检查
检查 observation 是否为空、维度是否为39、
是否存在 NaN 或 Inf。

R-03-02：关键物理变量阈值检查
依据经过确认的物理安全阈值进行判断。

R-03-03：连续状态变化检查
分析多个连续时间步的状态变化趋势。

## 5. 实施原则

1. 不将模型 Box 上下界直接视为工业安全阈值。
2. 不假设所有状态变量必须非负。
3. 不使用单个 observation 样本确定安全阈值。
4. 所有规则必须记录规则编号、触发变量和原因。
5. R-03 暂不接入正式执行拦截流程。
