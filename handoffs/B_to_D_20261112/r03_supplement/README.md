## 独立连续轨迹与标签：能推进的范围

新增`sensor_benchmark/`有**12个新建仿真环境/各一次reset/每条连续30步**，共360条成功step（另有12条reset记录），不拼接旧数据。源模型每步真实积分，动作均为合法零偏置，经现有D R-01/R-02审核；未启用R-03。

每条保留环境返回观察、投递给检测器的观察、裁剪前内部观察、请求/实际动作、reward、done/终止标志、step计数及仿真时间。episodes.json有episode、seed、初态内部状态哈希、注入时刻/幅度/变量、轨迹哈希和预先指定的分组划分。

| 分组 | 种子 | 完整轨迹/step | 标签依据 |

这套数据能让D真正拟合/评价一个**仿真+人工传感器故障范围的孤立森林基准**；不满足“已确认物理正常/异常工况”的训练/验收要求，不能改名冒充物理工艺异常检测。未训练模型，未报告准确率。
